## Prompt coverage and dependency order

| Requested stage | Delivered prompt | Eligibility |
| --- | --- | --- |
| Foundation | [01](../../prompts/01-foundation.md) | Next software milestone if the user explicitly chooses implementation in a later task. |
| Domain and fixtures | [02](../../prompts/02-domain-and-fixtures.md) | After foundation; synthetic or permission-cleared inputs only. |
| Local extension slice | [03](../../prompts/03-local-extension-slice.md) | After domain/storage acceptance; manual popup only. |
| Eligible retailer adapter | [04](../../prompts/04-eligible-retailer-adapter.md) | BLOCKED without exact method/field/use grant and approved narrow reader design. |
| Optional backend | [05](../../prompts/05-optional-backend.md) | DEFERRED/BLOCKED until P2 need, licensed redistributable facts, measured budget and deployment authorization. |
| Trustworthy comparison/history | [06](../../prompts/06-comparison-and-history.md) | Local lane follows 03 without 04/05. Public lane has separate source/service/accuracy gates. |
| Achievable alerts | [07](../../prompts/07-achievable-alerts.md) | DEFERRED; meaningful source/check semantics and observed user value must exist. |
| Release hardening | [08](../../prompts/08-release-hardening.md) | Private hardening after the selected local slice; public release remains gated. |

The selected private route is **01 → 02 → 03 → 06 → 08**. This is a dependency sequence for future work, not an instruction to implement those stages during research.
